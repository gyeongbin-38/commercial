## 2. Proposal templates

Rules: first sentence = their problem, never "Dear sir". Under 120 words.
Attach one relevant link, not all four.

### A. Standard (most jobs)

```
Hi [[name]],

[[one sentence showing you read the brief — e.g. "For a waitlist page
the fold has to do the convincing, so I'd lead with the product mock
and a single CTA rather than a feature list."]]

I design and build landing pages myself — no handoff, no waiting on a
second freelancer. Recent example (B2B SaaS, interactive demo,
validated lead form): gyeongbinbak.com

Fixed price, live preview from day one, [[X]] days turnaround. Happy to
send a one-paragraph direction idea before you commit.

[[Name]]
```

### B. When they mention conversion/CRO

```
Hi [[name]],

A landing page that "looks nice" is the $300 version of this job — the
part that costs more is structuring the argument: claim → proof →
objection handling → CTA, repeated down the page.

That's how I build. Design and Next.js development in one hand, so the
page that ships is the page that was designed. Example of the structure
I mean: gyeongbinbak.com

I can start [[date]] and put a design concept in front of you in 2–3
days. Fixed quote once I've seen the brief.

[[Name]]
```

### C. Short (high-competition jobs, apply fast)

```
Hi [[name]] — landing pages are all I do. Design + Next.js build, one
person, fixed price, live preview from day one.

Recent work: gyeongbinbak.com

If the style fits, I'll send a direction sketch before you commit to
anything.

[[Name]]
```

### What to bid on (first 60 days)

- Jobs posted <2h ago, under ~20 proposals
- Budget $300–1,500 — winnable now, review-worthy later
- Mentions of "conversion", "SaaS", "waitlist", "product launch"
- Skip: $50 budgets, "long-term partnership" unpaid trials, WordPress/
  Wix jobs (wrong buyers), anything asking for free spec work beyond a
  paragraph

## 5. Deploy checklist

```bash
npm install -g vercel        # once
vercel                       # from repo root — links + deploys
vercel --prod                # production
```

- `NEXT_PUBLIC_SITE_URL=https://gyeongbinbak.com` is set in Vercel and
  `.env.local`, so OG/sitemap URLs resolve to the custom domain.
- `video/showcase.mp4` is the 74s walkthrough for profile/gig uploads;
  re-record with `node scripts/showcase-video.mjs` after site changes.

## 6. First 60 days

1. Week 1: deploy, Upwork + 크몽 profiles live, project catalog published.
2. Weeks 2–4: 5–10 tailored proposals/day on Upwork; 크몽 gig promoted.
   Bid ~20% under target price until 3 reviews exist.
3. Weeks 5–8: raise prices on every new quote; convert one happy client
   into a written testimonial + permission to show the work.
4. Ongoing: every finished job → new portfolio card on the hub with the
   client's real result (signups, conversion, launch date).
